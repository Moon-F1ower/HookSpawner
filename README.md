> A lightweight bridge plugin for **RoseLoot** that brings your custom fishing drops to life.

**HookSpawner** intercepts specific items generated by RoseLoot when a player is fishing. Instead of just handing the item to the player, it can spawn mobs at the exact location of the fishing hook, optionally launching them directly at the player like a vanilla item pickup.

---

## ✨ Features

- **Library of Triggers:** Configure multiple item-to-mob combinations in a single `config.yml`.
- **Dynamic Spawning:** Spawns entities exactly where the fishing hook landed.
- **Projectile Physics:** Mobs can be launched towards the player. AI and gravity are temporarily disabled and seamlessly restored upon impact or arrival.
- **Item Management:** Choose whether the player keeps the original item (e.g., a barrel of loot) or if it's consumed as a trigger.
- **Anti-Duplication:** Fully safe. Trigger items are silently removed from the world if configured not to be kept.
- **Smart Safety Checks:** Automatically prevents infinite flying mobs if the player disconnects, teleports, or the mob hits a wall.
- **Localization:** Player messages and console logs support English and Russian.

---

## ⚙️ How it works with RoseLoot

This plugin is designed as a **companion** to [RoseLoot](https://modrinth.com/plugin/roseloot). 
1. **RoseLoot** decides *what* drops and with what chance.
2. **HookSpawner** decides *how* the server reacts to specific items.

---

## 📦 Installation

1. Install **RoseLoot** on your server.
2. Download `HookSpawner-x.y.z.jar` and place it in your server's `plugins/` folder.
3. Restart the server to generate the configuration files.
4. Open the folder **`plugins/HookSpawner/`** and edit `config.yml` to set up your triggers.
5. Set up RoseLoot to drop those exact items.

---

## 🧩 Configuration

All settings are located in **`plugins/HookSpawner/config.yml`**. 
*(After editing, use `/reload confirm` in-game or restart the server to apply changes).*

You can use `&` for color codes in names (the plugin translates them automatically).

```yaml
triggers:
  zombie_surprise:
    item: "ZOMBIE_HEAD"         
    name: "&cCursed Catch"    
    mob: "ZOMBIE"               
    amount: 1                   
    keep-item: false            
    fly-to-player: true         
```

### Configuration Fields
| Field | Type | Description |
|---|---|---|
| `item` | Material | The item ID that RoseLoot drops. |
| `name` | String | The custom display name of the item. Use `""` to ignore names. |
| `mob` | EntityType | The mob ID to spawn (e.g., `ZOMBIE`, `DROWNED`, `CREEPER`). |
| `amount` | int | Number of mobs to spawn. |
| `keep-item` | boolean | If `true`, the player receives the item. If `false`, the item is deleted. |
| `fly-to-player` | boolean | If `true`, the mob acts like a projectile and flies at the player. |
